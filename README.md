# 项目简介

这是一个基于 TqSdk + PySide6 的期货行情与实盘账户只读透明悬浮牌，带托盘图标和设置界面。项目仍然只负责展示，不提供任何交易操作。

## 功能说明

- 可选显示 0～1 条自定义大号行情及一行备注；关闭后不会创建该合约的行情订阅。
- 可分别开启实盘持仓和未成委托监控，每条记录直接显示对应合约的最新价；首笔行情到达前显示 `现—`。
- 持仓显示多空、数量、开仓均价、最新价和浮动盈亏。
- 未成委托显示方向、开平、剩余量、委托价和最新价。
- 账户状态采用 `已连接 66***01` 一类紧凑脱敏格式；委托和持仓不显示表头，通过间距分区。
- 默认完整顺序为“自定义行情 → 账户状态 → 委托 → 持仓”。
- 设置页可分别调整账户状态、未成委托和持仓的字号与相对位置，也可一键恢复自动无重叠排列。
- 应用层只建立一个实盘账户长连接；切换设置以及午休期间无行情更新都不会主动重复登录。
- 同一应用重复启动时，后启动的实例会在联网前退出，避免多个悬浮牌叠加。
- 托盘菜单支持显示/隐藏、锁定、设置和安全退出，并会记住样式与位置配置。
- 自定义合约支持输入补全和切换订阅，可使用 `KQ.m@交易所.品种` 或 `交易所.合约` 格式。

## 目录结构

- `tq_price_badge.py`：兼容原有启动方式的薄入口。
- `badge_app/frontend/`：Qt 界面层，负责悬浮牌、预览和设置对话框。
- `badge_app/backend/`：配置持久化、行情线程和实盘账户只读快照等后端逻辑。
- `badge_app/app.py`：应用编排层，负责连接前后端并管理线程生命周期。
- `tests/`：账户快照、界面布局、连接生命周期和只读安全测试。

## 环境变量

程序启动必须配置天勤行情认证：

```text
TQ_USER=天勤账号
TQ_PASS=天勤账号密码
```

只有开启实盘账户监控时，才另外需要以下三项：

```text
TQ_BROKER_ID=G国信期货
TQ_ACCOUNT_ID=实盘资金账号
TQ_ACCOUNT_PASS=实盘交易密码
```

当前实现不读取 `TQ_MODE`，也没有增加次席或国密环境变量。密码只从环境变量读取，不会写入项目的样式配置文件。新增或修改环境变量后，需要完全退出并重新启动程序。

`TqAccount` 登录会遵循 TqSdk 自身的结算确认和断线自动重连机制。项目不会主动重复创建实盘连接，但网络中断恢复时 SDK 可能重新登录。

## 启动

```powershell
pip install -r requirements.txt
python tq_price_badge.py KQ.m@SHFE.cu
```

如果本机已经配置桌面《监控悬浮牌.ps1》，可以继续使用该脚本启动。代码更新后，应先从托盘选择“退出”，等待图标完全消失，再启动一次。

## 只读安全边界

这里的“只读”专指项目不发送下单、撤单、转账、目标持仓或其他交易指令。仓库内的静态安全测试会扫描生产代码，阻止常见交易接口或交易任务类被引入。

离屏运行全部测试：

```powershell
$env:QT_QPA_PLATFORM = "offscreen"
python -m unittest discover -s tests -v
```
